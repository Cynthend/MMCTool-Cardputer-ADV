## Что это вообще такое?

Хотелось нормальный карманный инструмент на Cardputer-Adv, где можно зажимать аккорды, видеть настоящие ноты с диезами, крутить реверб с эхом и записывать демки прямо на флешку без компа. В итоге вырос **MMCTool**.

Один `.bin` работает сразу на **M5Stack Cardputer-Adv** (с ЦАП ES8311 и выходом 3.5 мм) и на обычном **M5Stack Cardputer**.

## Что умеет

- **10 живых DSP-инструментов (удержание 1.3с, чтобы случайно не сбить игру):**
  - `1` **BASS** - плотная бас-гитара с сабом и перегрузом
  - `2` **E-GTR** - электрогитара с 3 уровнями дисторшна (`CLN / CRN / HVY`)
  - `3` **LYRE** - хрустальная арфа (физика щипковой струны Karplus-Strong)
  - `4` **SYNTH** - универсальный синт (`SAW / SQR / TRI / PAD / Phonk BELL` на кнопке `7`)
  - `5` **DRUMS** - 3 набора ударных (кнопка `7`): **AMEN** (брейккор, звонкий крэш, дробь снейра), **TEKK** (хардтекк/габбер/пип кики + рейв-сирена), **PHNK** (808 трэп + коубелл + лазер)
  - `6` **DPAD** - MPC-режим: верхний ряд дает готовые аккорды в 1 кнопку (`Am, F, C, G, Dm, Em, E7, A7`), средний ряд - 808 бас, нижний - биты
  - `Esc` **PIANO** - акустическое пианино (сразу включает раскладку `PNO`)
  - `Tab` **REESE** - тягучий DnB / Sewerslvt Reese бас
  - `Fn` **CHAIN** - злой 4-пильный Chainsaw Supersaw лид под EDM и гиперпоп
  - `Ctrl` **ACID** - резонансный Acid 303
- **Нормальные ноты вместо непонятных цифр:**
  - В каждом кружочке показана реальная нота (`C, C#, D, F#...`)
  - Тоника выделена двойным кольцом, диезы (`#`) стилизованы под черные клавиши, слева стоят номера октав
  - В шапке видна текущая тональность (`K:Am`, `K:F#m`) и живой определитель аккордов (`[Am] A3 C4 E4`)
  - Быстрый сдвиг октав `-3..+3` кнопками `-` / `=` или боковой `G0` (`1x` вверх, `2x` вниз)
- **5 раскладок (удерж. `9` / `0`):** `MAJ` (мажор как лира в Genshin), `MIN` (минор), `PNO` (пианино с `#` сверху), `BIG` (широкие двойные клавиши под большие пальцы), `CHD` (живой перебор аккорда одной кнопкой).
- **Эффекты и громкость 200%:** Reverb (`O`), стерео-эхо (`P`), вибрато/тремоло (`K`), фильтр (`L`), фиксация сустейна в 1 клик (`M`), 30 уровней громкости до `200%` (`[` / `]`) с автоматическим бустом ES8311.
- **Запись WAV на SD и овердаб:**
  - Пишет стерео WAV в отдельную папку `/MMCTool_Rec/`, не мешая вашей музыке на флешке
  - Удерж. `\` - старт/стоп записи, удерж. `Enter` - проиграть (можно доигрывать поверх записи!), **клик + удержание `Enter`** открывает меню выбора записей, `Del` - принудительный стоп.
- **Тренажер мелодий GUIDE:** удерж. `/` включает подсветку нот из `/MMCTool_Songs/*.txt`. В репо лежит браузерный конвертер `index.html` для перевода `.mid` / `.mp3` / `.wav` в файлы для тренажера.
- **4 проработанные темы и 4 разные заставки (сохраняются в памяти):** `RETRO 84`, `AMBER CRT`, `CYBER 2077`, `GHOST WHITE`. Переключение: `G0` 3 раза подряд или удерж. `'`.

## Установка

- **`MMCTool_M5Launcher.bin`** - закинуть на microSD и поставить через [M5Launcher](https://github.com/bmorcelli/Launcher) от @bmorcelli.
- **`MMCTool_FullFlash_0x0.bin`** - прямая прошивка по USB на адрес `0x0` через M5Burner или Web ESPTool.

## Управление

| Клавиша | Действие |
| --- | --- |
| `Q..I` / `Aa..J` / `Opt..N` | Ровная сетка 3x8 (24 пэда) с плавно исчезающими волнами |
| Удерж. `1`..`6` / `Esc` / `Tab` / `Fn` / `Ctrl` | Смена инструмента (защита 1.3с) |
| Удерж. `7` | Набор барабанов (`AMEN/TEKK/PHNK`), волна синта или драйв |
| Удерж. `8` / Удерж. `9`,`0` | Визуализатор (Сетка волн / Осциллограф) / Раскладка |
| `-` / `=` или `G0` (1x / 2x) | Сдвиг октавы `-3..+3` |
| `[` / `]` | Громкость 0..200% (30 шагов + авто-буст ES8311) |
| Удерж. `O` / `P` / `K` / `L` | Reverb / Echo / Mod (Vib/Trem) / Фильтр |
| `M` / `Space` | Фиксация Sustain (1 клик) / Педаль Sustain (держать) |
| Удерж. `\` / Удерж. `Enter` / `Del` | Запись WAV / Старт-стоп записи / Принудительный стоп |
| Клик + удерж. `Enter` | Открыть меню записей `/MMCTool_Rec` |
| Удерж. `/` | Включить тренажер `GUIDE` (`/MMCTool_Songs/*.txt`) |
| `G0` (3x) или Удерж. `'` | Сменить тему (сохраняется при перезапуске) |
